プライバシーポリシー

本ポリシーは、個人利用専用Windowsアプリ「Video Backup v5」と、その説明サイトにおける情報の取り扱いを示します。

1. アクセスする情報

  • Googleアカウントのメールアドレス等、GmailとDriveが同じ本人のアカウントであることを確認するための情報。
  • GmailのメールID、受信日時、ラベル、件名、本文等。アプリは指定開始日以降の受信メールを確認するため、条件に一致しないメールの情報にも判定時にアクセスします。添付ファイル内部のURLは処理しません。
  • Google Driveの容量情報、アプリで扱うフォルダ・ファイルのID、名前、サイズ、チェックサム、親フォルダ等。
  • Google OAuthの認証情報、およびアップロード再開に必要な情報。
  • メール本文から抽出したYouTube動画URL・動画ID、動画タイトル、動画情報、取得・変換した動画ファイル。

2. 利用目的

これらの情報は、対象メールの判定、許可された動画の保存、既読・未読の変更、保存結果の確認、重複防止、処理の再開、エラー確認のために利用します。広告配信、情報の販売、信用判断、汎用AIモデルの開発・学習には利用しません。

3. 保存場所と保持

プログラムは本人のPCで動きます。処理記録・ログ・動画ファイルは、原則として本人のWindowsユーザーの %LOCALAPPDATA%\YouTubeMailDrive 以下に保存します。処理記録にはメールID・受信日時・アカウントのメールアドレス・動画ID・処理結果等を含みます。ログには動画URL、タイトル、ファイル名、処理日時、エラー等を含みます。メール本文全体を保存する機能はありません。

OAuthクライアント情報、トークン、アップロード再開先はWindows標準のDPAPIで暗号化してPC内に保存します。ログには認証情報を記録しない設計で、外部ツールの出力に含まれるURLや認証関連文字列は伏せます。動画情報は必要な項目だけを保持し、署名付き配信URLを含む情報全体は保存しません。

動画は本人のGoogle Drive専用フォルダにも保存します。PC内の動画・作業ファイル・処理記録には自動削除期限を設けていません。ログはファイルサイズに応じて世代管理します。本人が監視停止中にバックアップと整理を行います。

4. 外部への通信・共有

認証、メール確認、既読変更、動画の保存・照合のため、Googleの認証サービス、Gmail API、Google Drive APIと通信します。動画を取得するため、YouTubeおよびその配信先と通信し、抽出した動画ID等を送信します。

このアプリには、運用者独自の外部サーバーへメール本文や認証情報を送信する機能、広告サービスへの送信機能、分析サービスやAIサービスへの自動送信機能はありません。本人が問い合わせやバックアップ等のために自らデータを共有する場合は、その共有先と内容を本人が管理します。

5. Google APIデータの限定利用

Google APIから取得した情報の利用と移転は、Google API Services User Data PolicyおよびそのLimited Use要件に従います。取得情報はここに説明した本人向け機能の提供に限定して扱います。

6. アクセスの取消と削除

本人は監視を終了し、Googleアカウントの接続管理からこのアプリのアクセス権を取り消せます。PC内の保存データは、プログラム停止後に本人が削除できます。Driveの動画・フォルダは、本人がDrive上で削除できます。

Google側のアクセス権の取消だけでは、PCやDriveに保存済みのファイルは削除されません。処理記録を削除すると、後の再実行で動画が重複保存される可能性があります。

7. 説明サイトの情報

この説明サイトには入力フォーム、Google認証処理、アクセス解析スクリプト、独自の追跡Cookieを設置していません。GitHub Pagesで公開する際のアクセス情報の取り扱いは、GitHubのプライバシー声明もご確認ください。メールや動画のデータをこの説明サイトへアップロードする必要はありません。
